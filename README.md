# Fakoshima Perfumes — Academic Brand Presentation
### Contemporary Classic · Haute Parfumerie & Visual Identity Case Study

An avant-garde, ultra-minimalist, dark luxury single-page academic project presentation inspired by the aesthetic of **Fakoshima Perfumes** (fakoshimaperfumes.com).

## Project Structure & Content
- **Hero Section**: `FAKOSHIMA: CONTEMPORARY CLASSIC` with core USP and biomorphic emblem.
- **Section 01**: `01. Описание товара и целевой аудитории` (Product essence, target audience 22–38 YRS, psychographics).
- **Section 02**: `02. Уникальное торговое предложение (УТП)` (USP statement, VIPS philosophy, 4 tenets).
- **Section 03**: `03. Айдентика и логотип` (Approved biomorphic emblem, #050505 noir, #8A0303 crimson, #D4AF37 gold).
- **Section 04**: `04. Креативный бриф` (Campaign objectives, Tone of Voice, basic communication channels).
- **Section 05**: `05. Медиаплан на 1 год (без бюджета)` (Q1–Q4 seasonal roadmap without mass-market clichés).
